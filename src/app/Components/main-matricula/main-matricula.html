Proceso de matrícula

01. Selecciona tu idioma

Elige el idioma que deseas estudiar.

02. Elige tu nivel

Selecciona el nivel que corresponde a tus conocimientos.

03. Selecciona modalidad

Elige entre las modalidades disponibles.

04. Revisa los requisitos

Verifica los requisitos antes de realizar tu matrícula.

Completa el proceso de matrícula mediante los canales establecidos.
